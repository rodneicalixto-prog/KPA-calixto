# Command - criar

## Objetivo

Produzir uma peca de copy/conteudo especifica (ad, email, post, LP, script) a partir de estrategia e VOC ja existentes.

## Passos

1. Confirmar que existe estrategia aprovada (`Strategist`) e VOC minimo. Se nao existir, rodar `kpa-researcher` e `kpa-strategist` primeiro — nunca escrever copy sobre promessa sem mecanismo.
2. Carregar `04_DIRETRIZES/copy-goat-lite.md` e, se a entrega for final (nao rascunho), `04_DIRETRIZES/voz-ptbr.md`.
3. Rodar `03_TASKS/T03-copy-nucleus.md` adaptado ao formato pedido (ad, email, post, LP, script).
4. Rodar `GATE-COPY`.
5. Entregar como rascunho pro usuario revisar antes de publicar, enviar ou gastar verba.

## Saida

```yaml
piece_type:
copy_output:
gate_result:
open_gaps:
```
