# Checklist - Gate Memory

- [ ] Fontes da nota estao identificadas (de onde veio a informacao).
- [ ] Nao ha secrets (token, senha, credencial, dado pessoal sensivel) na nota.
- [ ] Nao ha contradicao silenciosa entre a nota e o ledger/context atual — conflito foi reportado, nao escondido.
- [ ] Nota tem projeto, tarefa e data.
- [ ] Links relevantes (projeto, decisao, execucao, skill) estao presentes.
- [ ] Notas duplicadas ou equivalentes foram consolidadas, nao empilhadas.
- [ ] Nenhuma acao externa (credencial, publicacao, mensagem, infraestrutura) foi tomada pelo curador de memoria.
