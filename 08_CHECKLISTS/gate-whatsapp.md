# Checklist - Gate WhatsApp

- [ ] Objetivo da conversa esta claro.
- [ ] Publico, oferta e tom foram considerados.
- [ ] Mensagens cabem em tela de celular.
- [ ] Cada etapa tem proximo passo claro.
- [ ] Bot nao finge ser humano.
- [ ] Provas e claims foram aprovados ou marcados como `[A PREENCHER]`.
- [ ] Existe handoff humano com responsavel e SLA.
- [ ] Existem stop rules.
- [ ] Existe opt-out quando houver abordagem ativa.
- [ ] Follow-up tem motivo contextual.
- [ ] Cowork docs estao em modo `draft` ate ativacao.
- [ ] Disparo real exige confirmacao humana.
