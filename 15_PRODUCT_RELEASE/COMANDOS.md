# Comandos essenciais

No Claude Desktop, use as palavras sem `/`. No Claude Code, ambas as formas funcionam.

| Comando | Resultado |
|---|---|
| `instalar kpa30` | executa o onboarding guiado |
| `start here` | identifica o próximo passo |
| `preflight acessos` | levanta acessos e bloqueios |
| `nova task` | cria uma tarefa controlada |
| `rodar pipeline` | executa a sequência operacional |
| `review gate` | revisa qualidade e riscos |
| `whatsapp system` | prepara sistema de WhatsApp em draft |
| `automatizar processo` | cria blueprint e SOP de automação |
| `forge` | cria componente novo seguindo o padrão do kit |

Se o comando envolver envio, publicação, gasto, credencial ou exclusão, o kit deve parar no gate de aprovação humana.
