# Comece aqui — Kit Piloto Automático V30

Esta é a entrada simples do kit. Você não precisa abrir as pastas internas para começar.

## Primeira sessão

1. Abra o Claude Code na pasta do kit ou crie o Project no Claude Desktop.
2. Digite `instalar kpa30`.
3. Informe apenas dados não sensíveis do negócio.
4. Escolha uma primeira ação concreta.
5. Revise a entrega antes de publicar, enviar mensagens ou gastar verba.

## Escolha uma ação

| Objetivo | Escreva no Claude |
|---|---|
| Organizar o negócio | `primeira tarefa` |
| Criar briefing | `fazer briefing` |
| Montar atendimento | `whatsapp system` |
| Automatizar uma rotina | `automatizar processo` |
| Revisar uma entrega | `review gate` |
| Configurar acessos | `preflight acessos` |

Tráfego pago é opcional e pode ser configurado depois. Nenhuma campanha, disparo, publicação ou gasto é autorizado apenas por instalar o kit.

## Regra de segurança

- nunca envie tokens ou senhas no chat;
- nunca coloque `.env` no Project Knowledge;
- mantenha outputs em `draft` até revisão humana;
- confirme separadamente qualquer ação irreversível.

Continue em `GUIA_DE_USO.md` para o fluxo diário.
