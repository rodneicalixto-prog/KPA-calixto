# Trilha essencial do operador

## Módulo 1 — Segurança e contexto

- separar dados públicos, internos e secretos;
- usar `.env` apenas localmente;
- definir objetivo, prazo, canal e responsável.

## Módulo 2 — Trabalhar em draft

- produzir uma primeira versão;
- marcar lacunas em vez de inventar;
- executar o gate antes de usar externamente.

## Módulo 3 — Operação diária

- abrir uma task por resultado;
- manter contexto mínimo;
- registrar decisões e handoffs.

## Módulo 4 — Integrações opcionais

- configurar MCPs somente quando necessários;
- validar leitura antes de habilitar automação;
- exigir aprovação separada para escrita.

## Conclusão

O operador concluiu a trilha quando consegue gerar uma entrega em draft, revisá-la, registrar a decisão e localizar o output sem compartilhar credenciais.
