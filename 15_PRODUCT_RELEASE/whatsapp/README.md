# WhatsApp

Destino publico dos fluxos WhatsApp da release V30.

Esta pasta deve ser gerada a partir de `12_WHATSAPP_STACK/`, mas escrita para usuario leigo.

Fluxos obrigatorios:

- prospeccao;
- atendimento SDR;
- sucesso do cliente;
- follow-up de vendas;
- onboarding;
- reativacao;
- handoff humano.

Os fluxos estao em `fluxos/`.

Regra: todo fluxo real com envio automatico deve nascer em modo `draft` e exigir confirmacao antes de ativar.
