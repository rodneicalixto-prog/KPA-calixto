# Fluxos WhatsApp

Todos os fluxos desta pasta estao em modo `draft`.

## Como usar

1. Escolha o fluxo pelo objetivo.
2. Substitua variaveis entre colchetes.
3. Rode `GATE-WHATSAPP`.
4. Teste com conversa ficticia.
5. So ative envio real com confirmacao humana.

## Fluxos

| Fluxo | Arquivo | Objetivo |
|---|---|---|
| Prospeccao | `prospeccao.md` | iniciar conversa com lead |
| SDR/Atendimento | `sdr-atendimento.md` | qualificar e encaminhar |
| Sucesso do Cliente | `sucesso-cliente.md` | acompanhar cliente ativo |
| Follow-up vendas | `follow-up-vendas.md` | retomar proposta/lead |
| Onboarding | `onboarding.md` | integrar cliente novo |
| Reativacao | `reativacao.md` | recuperar lead/cliente parado |
| Handoff humano | `handoff-humano.md` | transferir com contexto |
