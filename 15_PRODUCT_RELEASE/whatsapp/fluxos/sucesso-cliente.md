# WhatsApp — Sucesso do Cliente

Status: draft

## Objetivo

Acompanhar cliente ativo, detectar risco, pedir feedback e gerar proxima acao.

## Variaveis

- `[NOME]`
- `[PROJETO]`
- `[ENTREGA]`
- `[DATA]`
- `[PROXIMO_PASSO]`

## Check-in

```text
Oi, [NOME]. Passando pra checar como esta o andamento de [PROJETO].

De 0 a 10, como voce avalia ate aqui?

Se a nota for menor que 8, me diz o que mais precisa melhorar.
```

## Pos-entrega

```text
[NOME], a entrega [ENTREGA] ja esta pronta para sua revisao.

Quando puder, me manda:
1. aprovado;
2. ajustes pequenos;
3. precisa rever direcao.
```

## Risco detectado

```text
Entendi o ponto. Vou registrar isso como prioridade e encaminhar para revisao humana antes de seguir.
```

## Handoff humano

Transferir quando:

- nota menor que 8;
- reclamacao;
- pedido fora do escopo;
- risco de churn;
- conflito de expectativa.

## Stop rules

- nao discutir;
- nao prometer prazo novo sem confirmacao;
- nao admitir erro especifico sem validar contexto.
