# Stack recomendado por uso

## Por tipo de operacao

### Operacao base (qualquer mentorado)

| MCP | Cobre |
|---|---|
| Composio | Drive, Gmail, Calendar, Notion, Slack, Linear, ClickUp |
| Filesystem | Pastas locais do projeto |
| Playwright | Auditar LP, screenshots, testar fluxo |

### Trafego pago (Meta/Google)

| MCP | Cobre |
|---|---|
| Meta Ads CLI nativo | `/meta-cli-install` — gestao de campanhas Meta |
| Composio | Posts organicos em Facebook/Instagram, analytics |
| Firecrawl | Espionar criativos concorrentes |

### Vendas / WhatsApp

| MCP | Cobre |
|---|---|
| WhatsApp MCP (verygoodplugins) | Leitura/envio WhatsApp Web |
| Composio | CRM (HubSpot/Salesforce/Pipedrive), Gmail follow-up |

### Conteudo / Social

| MCP | Cobre |
|---|---|
| Composio | Postagem em X/Twitter, LinkedIn, Instagram, Facebook |
| Playwright | Capturar referencias visuais, screenshot |
| Firecrawl | Pesquisar tendencias |

### Desenvolvedor / Dev tools

| MCP | Cobre |
|---|---|
| GitHub MCP | Versionar projetos, criar PRs |
| Sequential Thinking | Raciocinio passo-a-passo |
| Context7 | Docs atualizadas de bibliotecas |

## Por segmento (familia operacional)

| Familia | Stack minimo recomendado |
|---|---|
| Servico local | Composio + WhatsApp MCP + Playwright |
| Profissional liberal | Composio + WhatsApp MCP |
| B2B consultivo | Composio (HubSpot/Salesforce) + WhatsApp MCP + Gmail |
| Ecommerce | Composio + WhatsApp MCP + Meta Ads CLI |
| Infoproduto | Composio + WhatsApp MCP + Meta Ads CLI + Playwright |
| Agencia/servico digital | Composio + Meta Ads CLI + Playwright + Firecrawl + GitHub |
| Clinica/saude | Composio + WhatsApp MCP (cuidado LGPD) |
| Juridico/regulado | Composio + Filesystem (cuidado confidencialidade) |
